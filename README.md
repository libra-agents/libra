# LIBRA: Programmatic Induction of Executable Tool Libraries

[![arXiv](https://img.shields.io/badge/arXiv-2611.05445-b31b1b.svg)](https://arxiv.org/abs/2611.05445)

LIBRA (Library Induction by Runtime Assembly) turns a flat tool catalog into an
executable tool library. An LLM proposes a contract for each tool (candidate
invocations, reusable outputs, state changes, and success conditions), and
LIBRA executes compositions of those contracts in a sandbox to keep only the
dependencies that hold at runtime. The library is built before any user query
and is used for one-shot and agentic tool retrieval.

Paper: https://arxiv.org/abs/2611.05445

## Repository structure

```text
.
├── retrieval/
│   ├── core/                 # contracts, field index, graph search, parallel runtime, retrieval
│   ├── adapters/             # AppWorld, BFCL, and SciTool execution adapters
│   ├── build_contracts.py    # generate per-tool contracts
│   ├── build_field_embeddings.py
│   ├── publish_graph.py      # reduce a discovery run to the compact dependency graph
│   ├── retrieve.py           # one-shot LIBRA retrieval
│   └── ...                   # baselines: BM25, TF-IDF, dense, TGR, Ego-Trip, SciToolKG, LLM predictor
├── agentic_retrieval/        # ToolReAGt agentic retrieval with pluggable backends
├── embedding/                # Qwen3 tool and query embeddings
├── scitool_container/        # HTTP server for executing SciToolAgent tools
├── scripts/                  # Slurm launchers and baseline/rerank scripts
├── util/convert_appworld.py  # AppWorld to retrieval format
├── dataset and embedding/    # benchmarks, tool registries, contracts, dependency graphs
├── data/bfcl/                # BFCL baseline inputs (TGR graph, Tool-DE profiles)
└── artifacts/                # encrypted AppWorld graph and contracts
```

Each benchmark directory under `dataset and embedding/` contains:

- `benchmark.jsonl`: queries and gold tool paths, used only for evaluation
- `tool_registry.json`: public tool metadata
- `contracts.json`: per-tool contracts generated by `deepseek-v4-flash`
- `dependency_graph.json`: the constructed dependency graph

| Benchmark | Tasks | Tools | Graph edges |
|---|---:|---:|---:|
| BFCL v4 multi-turn base | 200 | 128 | 672 |
| SciToolEval | 270 | 477 | 732 |

The AppWorld graph and contracts are provided in
`artifacts/appworld_dependency_graph_and_contracts.bundle` and unpack to
`dataset and embedding/appworld/`.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Graph construction and embedding use a local vLLM server
(`vllm/vllm-openai:v0.26.0-cu129`) with `Qwen/Qwen3-Embedding-0.6B`. Contract
generation uses the DeepSeek API (`DEEPSEEK_API_KEY`). The launchers in
`scripts/` target Slurm with Apptainer; runtime files are written under
`SKILL_MINING_ROOT` (default: `$SCRATCH/skill-mining`).

### Benchmarks

**AppWorld.** Install the official package and data, then unpack the
encrypted graph and contracts and convert the train/dev splits:

```bash
git clone https://github.com/StonyBrookNLP/appworld.git benchmark_code/appworld
cd benchmark_code/appworld && git lfs install && git lfs pull
pip install -e . && appworld install --repo && appworld download data
cd ../..

python - <<'PY'
from appworld.common.constants import PASSWORD, SALT
from appworld.common.crypto import unpack_bundle
unpack_bundle("artifacts/appworld_dependency_graph_and_contracts.bundle", ".", PASSWORD, SALT)
PY

python util/convert_appworld.py --appworld-root benchmark_code/appworld \
  --splits train,dev --output-dir "dataset and embedding/appworld"
```

Unpacked AppWorld files must not be redistributed in plain text.

**BFCL.** The converted data is included. Graph construction executes the
official tools from the Gorilla repository:

```bash
git clone --depth 1 https://github.com/ShishirPatil/gorilla.git \
  "$SKILL_MINING_ROOT/runtime/gorilla"
```

**SciToolEval.** Clone SciToolAgent into the repository root. Its tools are
served by `scitool_container/tool_server.py` (image definition in
`scitool_container/`). The graph job expects the image at
`$SKILL_MINING_ROOT/runtime/scitool-baseline.sif` and the tool dependencies at
`$SKILL_MINING_ROOT/runtime/scitool-python`.

```bash
git clone https://github.com/HICAI-ZJU/SciToolAgent.git SciToolAgent-main
```

## Usage

Build tool and query embeddings:

```bash
sbatch --partition=<partition> scripts/slurm_qwen_embeddings.job
```

Construct a dependency graph. `MODE=fresh` generates contracts with DeepSeek;
`MODE=warm` reuses the released `contracts.json`.

```bash
sbatch --partition=<partition> --export=MODE=fresh,DEEPSEEK_API_KEY scripts/slurm_bfcl_graph.job
sbatch --partition=<partition> --export=MODE=warm scripts/slurm_scitool_graph.job
sbatch --partition=<partition> --export=MODE=warm scripts/slurm_appworld_graph.job
```

Run one-shot retrieval with the released graphs:

```bash
python -m retrieval.retrieve bfcl \
  --embedding-root "$SKILL_MINING_ROOT/embeddings/qwen3_embedding_0.6b_v1" \
  --output-dir outputs/bfcl
```

Each run writes `predictions.jsonl` and `metrics.json`.
`scripts/slurm_dependency_retrieval.job` runs all three benchmarks.

Run agentic retrieval (dataset, representation, model, seed, retrieval mode):

```bash
sbatch --partition=<partition> scripts/run_toolreagt.job bfcl libra Qwen/Qwen3.5-9B 0 no_rerank
```

Baselines are launched with `scripts/setup_baselines.job`,
`scripts/build_baseline_embeddings.job`, `scripts/run_retrieval_baselines.job`,
and the `rerank_*` / `*egotrip*` / `*scikg*` scripts.
